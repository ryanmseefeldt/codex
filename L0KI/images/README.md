# Images Directory

## Required Assets

### Claude AI Logo

**File Name**: `Claude_AI_Logo.png`

**Location**: Place the Claude AI logo in this directory as `Claude_AI_Logo.png`

**Source**: Copy from `C:\Users\Owner\Downloads\Claude_AI_Logo.png` (Windows path)

**Usage**: The logo is displayed in multiple locations:
- Header when Claude AI is selected
- Model selector button
- Message headers for Claude AI responses

**Specifications**:
- Format: PNG (with transparency recommended)
- Recommended height: 40px for header, scales automatically
- Aspect ratio: Maintain original for best results

## Adding the Logo

1. Locate the Claude AI logo at: `C:\Users\Owner\Downloads\Claude_AI_Logo.png`
2. Copy the file to this directory
3. Rename to: `Claude_AI_Logo.png` (if not already named)
4. Verify the component loads the logo correctly

## Fallback Behavior

If the logo fails to load:
- The component will display a Sparkles icon as fallback
- No error will be thrown
- User experience remains functional
